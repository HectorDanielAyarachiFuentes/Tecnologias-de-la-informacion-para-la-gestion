# 🛠️ Herramientas y Módulos de Soporte Tecnológico

Este directorio agrupa las utilidades avanzadas, extensiones y entornos de integración tecnológica utilizados para potenciar la investigación y el desarrollo en la cátedra **Tecnología de la Información para la Gestión (TIG - CURZAS)**.

---

## 🧰 Módulos Disponibles

### 1. [NotebookLM (`NotebookLM/`)](./NotebookLM)
* **Propósito:** Integración de Google NotebookLM dentro de Antigravity IDE mediante el protocolo **MCP (Model Context Protocol)**.
* **Capacidades:** Consultas aumentadas por recuperación (RAG) sobre fuentes documentales de la cátedra, análisis cruzado de reglamentos públicos y generación asistida de síntesis académicas.
* **Componentes:**
  * `config/`: Archivos de configuración del servidor MCP.
  * `documentacion/`: Guías de integración y referencias de comandos.
  * `fuentes/`: Documentos de muestra clasificados por dominio.
  * `multimedia/`: Tutoriales y material audiovisual de apoyo.
